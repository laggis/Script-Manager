About ScriptManager

Local desktop manager for Node.js, Python, Batch and PowerShell scripts on Windows — no Docker, no containers. Minimises to system tray. Scripts are stored next to the .exe so they are easy to back up and move between machines.

Build as .exe

1. Install Node.js v18+ on your machine
2. npm install — installs all dependencies
3. npm run build — builds installer + portable into dist/
4. Run ScriptManager-Portable-1.4.0.exe — scripts.json will be created next to it automatically
